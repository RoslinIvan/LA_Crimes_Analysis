# Projet_UA3_Analyse_de_donn-es
Projet: Lutte contre la criminalité

Introduction   
Le jeu de données étudié contient près d’un million d’enregistrements relatifs aux incidents criminels signalés par la police. Chaque ligne correspond à un incident unique, identifié par un numéro d’enregistrement. Les variables couvrent différents aspects : la temporalité des événements, leur localisation géographique, les caractéristiques du crime et de la victime, ainsi que des informations administratives liées au traitement de l’affaire.

Description des variables  
— DR_NO : Numéro d’incident unique attribué par la police pour identifier chaque dossier. — Date Rptd : Date à laquelle l’incident a été signalé aux autorités. — DATE OCC : Date réelle de survenue de l’incident. — TIME OCC : Heure approximative de l’incident, exprimée au format horaire militaire. — AREA : Code numérique identifiant la zone géographique de l’incident. — AREA NAME : Nom correspondant à la zone de police (exemple : Central, Hollywood). — Rpt Dist No : Numéro du district de police où l’incident a été enregistré. — Part 1-2 : Classification de l’incident selon la typologie nationale des crimes (Partie 1 pour les crimes majeurs, Partie 2 pour les infractions mineures). — Crm Cd : Code numérique associé au type d’infraction. — Crm Cd Desc : Description textuelle du type de crime (exemple : vol, cambriolage). — Mocodes : Codes décrivant le modus operandi de l’auteur, pouvant inclure plusieurs valeurs. — Vict Age : Âge de la victime. 1— Vict Sex : Sexe de la victime (masculin, féminin ou inconnu). — Vict Descent : Origine ethnique de la victime, selon la codification policière. — Premis Cd : Code numérique représentant le type de lieu où le crime s’est produit. — Premis Desc : Description textuelle du lieu (exemple : domicile, rue, commerce). — Weapon Used Cd : Code identifiant l’arme utilisée lors de l’incident. — Weapon Desc : Description textuelle de l’arme employée (exemple : arme à feu, couteau). — Status : Code du statut de l’enquête ou du traitement de l’incident. — Status Desc : Description textuelle du statut (exemple : suspect arrêté, enquête en cours). — Crm Cd 1 à 4 : Codes additionnels associés à un même incident, permettant de préciser des infractions multiples. — LOCATION : Adresse ou localisation précise de l’incident. — Cross Street : Rue croisée la plus proche de l’incident, lorsque disponible. — LAT : Latitude géographique de l’incident. — LON : Longitude géographique de l’incident.

Problematique générale  
Comment analyser et modéliser les données criminelles pour identifier des tendances, comprendre les facteurs associés aux crimes, et prédire certains comportements criminels ? Les autorités policieres souhaites repondre à ces questions après une analyse approfondies des données : — Quelles sont les tendances temporelles et géographiques de la criminalité dans la ville ? — Y a-t-il des zones plus touchées à certaines périodes de la journée, du mois ou de l’année ? — Peut-on prédire le type de crime en fonction du lieu, de l’heure, et d’autres variables contextuelles ? — Quels facteurs (arme utilisée, lieu, heure, âge/genre de la victime, etc.) influencent le plus la gravité d’un crime — Quels sont les facteurs qui influencent la nature du crime ? — Etc... Ce jeu de données constitue donc une base solide pour mener des analyses exploratoires, statistiques et prédictives sur les phénomènes criminels.
